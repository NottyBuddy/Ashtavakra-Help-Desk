# IndiFrame Agent Portal — HRHNEXT · Agent Help Desk

A GitHub-hosted recreation of the IndiFrame Agent Portal knowledge hub.

## Current implementation

- Responsive navigation and home dashboard
- Scripts library with 20 section titles and available approved source content for General Guidelines, Mandatory Discovery Questions, and Lead Stage & Routing Rules
- Product guide with window types, glass options, colours, and qualification guidance
- Process SOP timeline
- FAQ and objection-handling reference
- Sales Team directory with search and city filter
- Latest Updates / Change Log
- My Quick Access (browser-local favorites)
- CX Questions search (100 supplied questions)

## Explicit exclusions

The following are intentionally not included anywhere in the portal navigation or as standalone modules:

- Log Call / Log Call Outcome
- Escalation / Escalation Matrix

## Run locally

Open `index.html` in a modern browser. No build step or external package is required.

## Publish with GitHub Pages

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`.
4. Save. GitHub Pages will publish the portal after deployment completes.

## Content governance

The uploaded IndiFrame Library documents are the source of truth. Any item marked under review or described as sample content must not be treated as approved. Verify current pricing, warranty terms, serviceability, product availability, and technical claims against the latest approved source before customer communication.
